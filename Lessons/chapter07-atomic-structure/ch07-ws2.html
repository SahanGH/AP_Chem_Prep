Chapter 7 • Atomic Structure and Periodicity

Worksheet 2 • Electron Configurations

Zumdahl §7.11 • build the ion first, then configure it

Directions & data
Write configurations from memory using the periodic table's block structure, then check. For ions, adjust the electron count before you write anything.
1. Write full electron configurations:
  1. \(\ce{N}\): \(1s^2 2s^2 2p^3\)
  2. \(\ce{Al}\): \(1s^2 2s^2 2p^6 3s^2 3p^1\)
  3. \(\ce{Ar}\): \(1s^2 2s^2 2p^6 3s^2 3p^6\)
2. Write noble-gas shorthand configurations:
  1. \(\ce{Se}\): \([\ce{Ar}]4s^2 3d^{10} 4p^4\)
  2. \(\ce{Sr}\): \([\ce{Kr}]5s^2\)
  3. \(\ce{Mn}\): \([\ce{Ar}]4s^2 3d^5\)
  4. \(\ce{I}\): \([\ce{Kr}]5s^2 4d^{10} 5p^5\)
3. Ions — adjust the electron count first:
  1. \(\ce{Ca^2+}\): \([\ce{Ar}]\)
  2. \(\ce{P^3-}\): \([\ce{Ar}]\)
  3. \(\ce{Fe^2+}\): \([\ce{Ar}]3d^6\)
  4. \(\ce{Fe^3+}\): \([\ce{Ar}]3d^5\)
  5. \(\ce{Zn^2+}\): \([\ce{Ar}]3d^{10}\)
4. Transition-metal cations lose 4\(s\) electrons before 3\(d\), even though 4\(s\) filled first. State the rule and apply it to explain why \(\ce{Fe^2+}\) is \([\ce{Ar}]3d^6\) rather than \([\ce{Ar}]4s^2 3d^4\).
5. Unpaired electrons. Give the number in the ground state:
  1. \(\ce{C}\): 2
  2. \(\ce{O}\): 2
  3. \(\ce{Fe^3+}\): 5
  4. \(\ce{Zn}\): 0
6. Classify each as ground state, excited state, or impossible — and identify the species where one exists:
  1. \(1s^2 2s^2 2p^6 3s^1\): ground — Na
  2. \(1s^2 2s^2 2p^6 3s^2 3p^5 4s^1\) (18 e\(^-\)): excited Ar
  3. \(1s^2 2s^2 2p^6 3s^3\): impossible (\(s\) max 2)
  4. \(1s^2 2s^1 2p^1\) (4 e\(^-\)): excited Be
7. The two exceptions:
  1. Predicted vs actual configuration of \(\ce{Cr}\): \([\ce{Ar}]4s^2 3d^4\) vs \([\ce{Ar}]4s^1 3d^5\)
  2. Predicted vs actual configuration of \(\ce{Cu}\): \([\ce{Ar}]4s^2 3d^9\) vs \([\ce{Ar}]4s^1 3d^{10}\)
  3. Give the reason both anomalies occur.
8. Name three species isoelectronic with \(\ce{Ne}\) and state their shared configuration.
