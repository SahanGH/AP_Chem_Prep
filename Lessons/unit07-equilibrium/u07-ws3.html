CED 7.7 • the 5% check is part of the answer, not a formality

Directions & data
Set up Initial / Change / Equilibrium, drive the change row from the coefficients, then substitute into \(K\) • approximate only when justified, and always report the percentage.
1. CED 7.7 ICE tables and the BCA tables from Unit 4 have the same shape. State the one difference and why it arises.
2. CED 7.7 \(\ce{A <=> B + C}\) with \(K = 1.0\times10^{-5}\) and \([\ce{A}]_0 = 0.100\,\mathrm{M}\).
  1. Complete the equilibrium row: \([\ce{A}] = \) \(0.100 - x\), \([\ce{B}] = [\ce{C}] = \) \(x\)
  2. Write the \(K\) expression in terms of \(x\). \(x^2/(0.100 - x)\)
  3. Apply the small-\(x\) approximation and solve.
    \(x^2/0.100 \approx 1.0\times10^{-5}\); \(x^2 = 1.0\times10^{-6}\); \(x = \mathbf{1.0\times10^{-3}}\) M
  4. Carry out the 5% check explicitly.
  5. Give the three equilibrium concentrations. \([\ce{A}] = 0.099\); \([\ce{B}] = [\ce{C}] = 1.0\times10^{-3}\)
3. CED 7.7 \(\ce{A <=> 2B}\) with \(K = 4.0\times10^{-6}\) and \([\ce{A}]_0 = 0.50\,\mathrm{M}\).
  1. Why is the change in B written as \(+2x\) rather than \(+x\)?
  2. Solve for \([\ce{B}]\) at equilibrium.
    \(K = (2x)^2/(0.50-x) \approx 4x^2/0.50\); \(4x^2 = 2.0\times10^{-6}\); \(x = 7.1\times10^{-4}\); \([\ce{B}] = 2x = \mathbf{1.4\times10^{-3}}\) M
  3. Check the approximation. \(0.14\%\) — valid
4. CED 7.7 The same setup as problem 2 — \(\ce{A <=> B + C}\) with \([\ce{A}]_0 = 0.100\) — but now \(K = 0.20\).
  1. Apply the small-\(x\) approximation and report the value it gives. \(x = 0.141\)
  2. Carry out the check. What does it show?
  3. Solve properly with the quadratic.
    \(x^2 = 0.20(0.100 - x)\), so \(x^2 + 0.20x - 0.020 = 0\). \(x = [-0.20 + \sqrt{0.040 + 0.080}]/2 = (-0.20 + 0.3464)/2 = \mathbf{0.073}\) M
  4. By what percentage was the approximation wrong? about 93%
5. CED 7.7 For each case, predict whether the small-\(x\) approximation will hold, and say why:
  1. \(K = 1\times10^{-8}\), \([\ce{A}]_0 = 1.0\) M valid — \(K\) is minute beside \([\ce{A}]_0\)
  2. \(K = 2.0\), \([\ce{A}]_0 = 0.10\) M invalid — \(K\) exceeds \([\ce{A}]_0\)
  3. \(K = 1\times10^{-6}\), \([\ce{A}]_0 = 1\times10^{-5}\) M
6. CED 7.7 \(\ce{H2 + I2 <=> 2HI}\) with \(K = 50.0\) and both reactants starting at 1.00 M.
  1. Write \(K\) in terms of \(x\) and explain why no quadratic formula is needed.
  2. Solve for \(x\).
    \(2x/(1.00-x) = \sqrt{50.0} = 7.07\); \(2x = 7.07 - 7.07x\); \(9.07x = 7.07\); \(x = \mathbf{0.780}\)
  3. Give the three equilibrium concentrations. \([\ce{H2}] = [\ce{I2}] = 0.220\); \([\ce{HI}] = 1.56\)
  4. Verify by substituting back into \(K\).
    \((1.56)^2/(0.220)^2 = 2.43/0.0484 = \mathbf{50.2}\) — agrees with 50.0 to rounding ✓
7. CED 7.7 Solve \(\ce{A <=> 2B}\) with \(K = 0.50\) and \([\ce{A}]_0 = 1.00\,\mathrm{M}\) using the quadratic formula.
\(K = 4x^2/(1.00 - x) = 0.50\), so \(4x^2 = 0.50 - 0.50x\) and \(4x^2 + 0.50x - 0.50 = 0\). \(x = [-0.50 + \sqrt{0.25 + 8.0}]/8 = (-0.50 + 2.872)/8 = \mathbf{0.297}\). So \([\ce{A}] = 0.703\) M and \([\ce{B}] = 0.593\) M.
8. CED 7.7 Why is a negative root always discarded when solving an equilibrium quadratic?
Spiral review • Unit 7 • blocks 1–3
  1. Reversing a reaction gives \(K = \) \(1/K\)
  2. Doubling coefficients gives \(K = \) \(K^2\)
  3. \(K \gg 1\) favors: products
  4. \(Q > K\) means the system shifts: left
  5. Only what changes \(K\)? temperature
