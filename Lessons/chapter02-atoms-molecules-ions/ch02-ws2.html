Chapter 2 • Atoms, Molecules, and Ions

Worksheet 2 • Nomenclature Drill

Zumdahl §2.8 • fluency sheet — do it twice, timed the second time

Directions & data
Write the compound TYPE beside each answer (I ionic-fixed, II ionic-variable, III covalent, A acid). Naming errors are almost always type-identification errors.
1. Name each ionic compound (Type I — fixed-charge metal):
  1. \(\ce{KBr}\): potassium bromide
  2. \(\ce{MgS}\): magnesium sulfide
  3. \(\ce{Al2O3}\): aluminum oxide
  4. \(\ce{Ca3N2}\): calcium nitride
  5. \(\ce{ZnCl2}\): zinc chloride (no numeral needed)
2. Name each (Type II — variable-charge metal). Deduce the charge from the anions first.
  1. \(\ce{FeCl2}\): iron(II) chloride
  2. \(\ce{Cu2O}\): copper(I) oxide
  3. \(\ce{SnO2}\): tin(IV) oxide
  4. \(\ce{PbS}\): lead(II) sulfide
  5. \(\ce{Cr2S3}\): chromium(III) sulfide
3. Name each compound containing a polyatomic ion:
  1. \(\ce{Na2SO4}\): sodium sulfate
  2. \(\ce{Mg(OH)2}\): magnesium hydroxide
  3. \(\ce{Fe(NO3)3}\): iron(III) nitrate
  4. \(\ce{(NH4)2CO3}\): ammonium carbonate
  5. \(\ce{KH2PO4}\): potassium dihydrogen phosphate
  6. \(\ce{Ca(ClO)2}\): calcium hypochlorite
4. Name each binary covalent compound (Type III):
  1. \(\ce{SO3}\): sulfur trioxide
  2. \(\ce{N2O4}\): dinitrogen tetroxide
  3. \(\ce{PCl5}\): phosphorus pentachloride
  4. \(\ce{CCl4}\): carbon tetrachloride
5. Name each acid:
  1. \(\ce{HBr(aq)}\): hydrobromic acid
  2. \(\ce{HNO3(aq)}\): nitric acid
  3. \(\ce{H2SO3(aq)}\): sulfurous acid
  4. \(\ce{H3PO4(aq)}\): phosphoric acid
6. Write the formula for each name:
  1. barium hydroxide: \(\ce{Ba(OH)2}\)
  2. manganese(II) nitrate: \(\ce{Mn(NO3)2}\)
  3. diphosphorus pentoxide: \(\ce{P2O5}\)
  4. ammonium phosphate: \(\ce{(NH4)3PO4}\)
  5. hydrofluoric acid: \(\ce{HF(aq)}\)
  6. sodium hypochlorite: \(\ce{NaOCl}\)
  7. copper(II) sulfate: \(\ce{CuSO4}\)
  8. potassium bromate: \(\ce{KBrO3}\)
7. Error hunt — each name below is wrong. Give the correct one and say which rule was broken.
  1. \(\ce{FeO}\) called “iron oxide”
  2. \(\ce{Mg3N2}\) called “trimagnesium dinitride”
  3. \(\ce{Cu(NO3)2}\) called “copper(II) nitride”
