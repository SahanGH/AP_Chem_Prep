Zumdahl §17.6–17.7 • entropies are in joules, enthalpies in kilojoules

Directions & data
Zumdahl Appendix 4. Columns: \(\Delta H_f^\circ\) (kJ/mol), \(\Delta G_f^\circ\) (kJ/mol), \(S^\circ\) (J/K\(\cdot\)mol). \(\ce{H2}\) 0, 0, 131 • \(\ce{O2}\) 0, 0, 205 • \(\ce{N2}\) 0, 0, 192 •\ \(\ce{C(gr)}\) 0, 0, 6 • \(\ce{H2O(l)}\) \(-286\), \(-237\), 70 •\ \(\ce{H2O(g)}\) \(-242\), \(-229\), 189 • \(\ce{CO2}\) \(-393.5\), \(-394\), 214 • \(\ce{CO}\) \(-110.5\), \(-137\), 198 • \(\ce{CH4}\) \(-75\), \(-51\), 186 • \(\ce{NH3}\) \(-46\), \(-17\), 193 • \(\ce{NO}\) 90, 87, 211 • \(\ce{NO2}\) 34, 52, 240 • \(\ce{N2O4}\) 10, 98, 304 • \(\ce{HCl}\) \(-92\), \(-95\), 187 • \(\ce{Cl2}\) 0, 0, 223.
1. Why can a table list an absolute \(S^\circ\) but only a \(\Delta H_f^\circ\)?
2. Consequently, \(S^\circ\) for an element in its standard state is not zero, while \(\Delta H_f^\circ\) for that element is zero. Give the value of \(S^\circ\) for \(\ce{O2(g)}\) as evidence. 205 J/(K\(\cdot\)mol)
3. Calculate \(\Delta S^\circ\) for each reaction. Check each answer against the sign you would have predicted:
  1. \(\ce{2NO(g) + O2(g) -> 2NO2(g)}\)
    \(2(240) - [2(211) + 205] = 480 - 627 = \mathbf{-147}~\mathrm{J/K}\); predicted negative (3 mol gas \(\to\) 2) ✓
  2. \(\ce{2CO(g) + O2(g) -> 2CO2(g)}\)
    \(2(214) - [2(198) + 205] = 428 - 601 = \mathbf{-173}~\mathrm{J/K}\); predicted negative ✓
  3. \(\ce{N2O4(g) -> 2NO2(g)}\) \(+176\) J/K
  4. \(\ce{H2(g) + Cl2(g) -> 2HCl(g)}\) \(+20\) J/K
  5. \(\ce{2H2O(l) -> 2H2(g) + O2(g)}\)
    \([2(131) + 205] - 2(70) = 467 - 140 = \mathbf{+327}~\mathrm{J/K}\)
4. Calculate \(\Delta H^\circ\) and then \(\Delta G^\circ\) at 298 K for \(\ce{2NO(g) + O2(g) -> 2NO2(g)}\) using \(\Delta G^\circ = \Delta H^\circ - T\Delta S^\circ\). Use your \(\Delta S^\circ\) from problem 3(a).
\(\Delta H^\circ = 2(34) - 2(90) = 68 - 180 = -112\) kJ. Converting the entropy, \(\Delta S^\circ = -0.147\) kJ/K. \(\Delta G^\circ = -112 - (298)(-0.147) = -112 + 43.8 = \mathbf{-68}~\text{kJ}\) — thermodynamically favored.
5. Now calculate \(\Delta G^\circ\) for the same reaction the other way, from \(\Delta G_f^\circ\) values.
  1. Set up and evaluate.
    \(\Delta G^\circ = 2(52) - [2(87) + 0] = 104 - 174 = \mathbf{-70}~\text{kJ}\)
  2. The two routes give \(-68\) and \(-70\) kJ. Is one of them wrong?
6. Unit discipline. A student calculates \(\Delta G^\circ\) for a reaction with \(\Delta H^\circ = -92\) kJ and \(\Delta S^\circ = -199\) J/K as \(-92 - 298(-199) = +59{,}210\).
  1. Identify the error.
  2. Give the correct value.
    \(-92 - 298(-0.199) = -92 + 59.3 = \mathbf{-33}~\text{kJ}\)
  3. Their answer was wrong by roughly what factor? about 1000
7. Calculate \(\Delta H^\circ\), \(\Delta S^\circ\) and \(\Delta G^\circ\) at 298 K for the combustion of methane, \(\ce{CH4(g) + 2O2(g) -> CO2(g) + 2H2O(l)}\).
\(\Delta H^\circ = [-393.5 + 2(-286)] - [-75] = -965.5 + 75 = -890.5\) kJ.
\(\Delta S^\circ = [214 + 2(70)] - [186 + 2(205)] = 354 - 596 = -242\) J/K.
\(\Delta G^\circ = -890.5 - 298(-0.242) = -890.5 + 72.1 = \mathbf{-818}~\text{kJ}\). From \(\Delta G_f^\circ\): \([-394 + 2(-237)] - [-51] = -817\) kJ ✓
8. For \(\ce{2CuO(s) -> 2Cu(s) + O2(g)}\), \(\Delta H^\circ = +312\) kJ and \(\Delta S^\circ = +185\) J/K.
  1. Calculate \(\Delta G^\circ\) at 298 K.
    \(312 - 298(0.185) = 312 - 55.1 = \mathbf{+257}~\text{kJ}\) — not favored
  2. Is copper(II) oxide stable at room temperature? Justify from your answer.
9. Rank these three by increasing \(\Delta S^\circ\) without calculating, then say which one you could not have ranked confidently: \(\ce{2H2O(l) -> 2H2(g) + O2(g)}\), \(\ce{N2(g) + 3H2(g) -> 2NH3(g)}\), \(\ce{H2(g) + Cl2(g) -> 2HCl(g)}\).
