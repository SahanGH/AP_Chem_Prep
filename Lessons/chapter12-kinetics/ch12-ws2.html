Zumdahl §12.4 • the linear plot identifies the order

Directions & data
State which plot is linear before computing anything. Remember that \(\ln[\ce{A}]\) is linear in time for first order — concentrations themselves are not, so never average them.
1. Complete the table from memory:
OrderIntegrated formLinear plotHalf-life
0\([\ce{A}]_t = -kt + [\ce{A}]_0\)\([\ce{A}]\) vs \(t\)\([\ce{A}]_0/2k\)
1\(\ln[\ce{A}]_t = -kt + \ln[\ce{A}]_0\)\(\ln[\ce{A}]\) vs \(t\)\(0.693/k\)
2\(1/[\ce{A}]_t = kt + 1/[\ce{A}]_0\)\(1/[\ce{A}]\) vs \(t\)\(1/(k[\ce{A}]_0)\)
2. Identify the order from each observation:
  1. A plot of \(\ln[\ce{A}]\) versus time is a straight line: first
  2. A plot of \([\ce{A}]\) versus time is a straight line: zero
  3. Half-life is independent of starting concentration: first
  4. A plot of \(1/[\ce{A}]\) versus time is a straight line: second
3. Explain why only first-order reactions have a half-life independent of concentration, and give one real consequence.
4. A first-order reaction has \(k = 0.0250\,\mathrm{/s}\) and \([\ce{A}]_0 = 1.20\,\mathrm{M}\).
  1. Half-life: 27.7 s
  2. \([\ce{A}]\) after 60.0 s:
    \(\ln[\ce{A}] = -(0.0250)(60.0) + \ln(1.20) = -1.500 + 0.1823 = -1.318\); \([\ce{A}] = 0.268\,\mathrm{M}\)
  3. Time for \([\ce{A}]\) to fall to 0.150 M:
    \(\ln(0.150/1.20) = -kt\); \(-2.079 = -0.0250t\); \(t = 83.2\,\mathrm{s}\) — three half-lives
5. Zumdahl's \(\ce{N2O5}\) data: \([\ce{N2O5}]_0 = 0.1000\,\mathrm{M}\), falling to 0.0500 M at 100 s and 0.0250 M at 200 s.
  1. What order is the reaction, and how do the data show it?
  2. Calculate \(k\). 6.93e-3 /s
  3. A student estimates \([\ce{N2O5}]\) at 150 s by averaging 0.0500 and 0.0250 to get 0.0375 M. Explain why this is wrong and compute the correct value.
    It is \(\ln[\ce{A}]\), not \([\ce{A}]\), that is linear in time, so linear interpolation of concentration is invalid. \(\ln[\ce{A}] = -(6.93\times10^{-3})(150.) + \ln(0.1000) = -3.343\); \([\ce{A}] = 0.0353\,\mathrm{M}\)
6. A first-order reaction has \(t_{1/2} = 12.0\,\mathrm{min}\).
  1. Value of \(k\): 0.0578 /min
  2. Fraction remaining after 36.0 min: 1/8
  3. Fraction remaining after 48.0 min: 1/16
7. A second-order reaction has \(k = 0.500\,\mathrm{/M/s}\) and \([\ce{A}]_0 = 0.200\,\mathrm{M}\).
  1. Half-life: 10.0 s
  2. \([\ce{A}]\) after 20.0 s:
    \(1/[\ce{A}] = (0.500)(20.0) + 1/0.200 = 10.0 + 5.00 = 15.0\); \([\ce{A}] = 0.0667\,\mathrm{M}\)
  3. Explain why the second half-life is longer than the first for a second-order reaction.
