2. Why does the solid never appear in a \(K_{sp}\) expression? Give the reason, not just the rule.
3. Complete the table relating molar solubility \(s\) to \(K_{sp}\):
  1. \(\ce{MX}\) (e.g. \(\ce{AgCl}\)): ions are \(s\) and \(s\), so \(K_{sp} = \) \(s^2\)
  2. \(\ce{MX2}\) (e.g. \(\ce{PbI2}\)): ions are \(s\) and \(2s\), so \(K_{sp} = \) \((s)(2s)^2 = 4s^3\)
  3. \(\ce{M2X}\) (e.g. \(\ce{Ag2CrO4}\)): ions are \(2s\) and \(s\), so \(K_{sp} = \) \((2s)^2(s) = 4s^3\)
  4. \(\ce{M3X}\) (e.g. \(\ce{Ag3PO4}\)): \(K_{sp} = \) \((3s)^3(s) = 27s^4\)
  5. Why do \(\ce{MX2}\) and \(\ce{M2X}\) give the same formula?
4. Calculate \(K_{sp}\) from each measured solubility:
  1. \(\ce{AgBr}\), \(s = 7.1\times10^{-7}\) M.
    \(K_{sp} = (7.1\times10^{-7})^2 = \mathbf{5.0\times10^{-13}}\)
  2. \(\ce{SrSO4}\), \(s = 5.7\times10^{-4}\) M. \(3.2\times10^{-7}\)
  3. \(\ce{CaF2}\), \(s = 2.2\times10^{-4}\) M.
    \([\ce{Ca^2+}] = 2.2\times10^{-4}\), \([\ce{F-}] = 4.4\times10^{-4}\); \(K_{sp} = (2.2\times10^{-4})(4.4\times10^{-4})^2 = \mathbf{4.3\times10^{-11}}\)
  4. \(\ce{Ag2CrO4}\), \(s = 1.3\times10^{-4}\) M.
    \([\ce{Ag+}] = 2.6\times10^{-4}\), \([\ce{CrO4^2-}] = 1.3\times10^{-4}\); \(K_{sp} = (2.6\times10^{-4})^2(1.3\times10^{-4}) = \mathbf{8.8\times10^{-12}}\)
5. Grams first, then moles.
  1. \(\ce{BaSO4}\) dissolves to \(9.0\times10^{-3}\) g/L. Convert to molar solubility and find \(K_{sp}\).
    \(s = 9.0\times10^{-3}/233.4 = 3.86\times10^{-5}\) M; \(K_{sp} = (3.86\times10^{-5})^2 = \mathbf{1.5\times10^{-9}}\)
  2. \(\ce{PbI2}\) dissolves to 0.70 g/L. Find \(K_{sp}\).
    \(s = 0.70/461.0 = 1.52\times10^{-3}\) M; \([\ce{I-}] = 3.04\times10^{-3}\); \(K_{sp} = (1.52\times10^{-3})(3.04\times10^{-3})^2 = \mathbf{1.4\times10^{-8}}\)
  3. \(\ce{CaCO3}\) dissolves to \(9.3\times10^{-3}\) g/L. Find \(K_{sp}\).
    \(s = 9.3\times10^{-3}/100.1 = 9.29\times10^{-5}\) M; \(K_{sp} = \mathbf{8.6\times10^{-9}}\)
6. A student calculates \(K_{sp}\) for \(\ce{PbI2}\) from \(s = 1.5\times10^{-3}\) M as \((1.5\times10^{-3})^3 = 3.4\times10^{-9}\).
  1. Identify the error.
  2. By what factor is their answer wrong? a factor of 4 (too small)
  3. Give the correct value. \(1.4\times10^{-8}\)
7. Explain the difference between these two statements, using \(\ce{AgCl}\) as your example: (i) “\(K_{sp}\) for \(\ce{AgCl}\) is \(1.6\times10^{-10}\)” and (ii) “the solubility of \(\ce{AgCl}\) is \(1.3\times10^{-5}\) M.”
