Worksheet 2 • Net Ionic Equations and Reaction Types

CED 4.2, 4.7, 4.8 • decide strong vs weak before you write

Directions & data
State the reaction type first, then write the equation. For every species you keep whole, be ready to say why.
1. Classify each reaction as precipitation, acid–base, or redox:
  1. \(\ce{2 K(s) + Br2(l) -> 2 KBr(s)}\): redox
  2. \(\ce{HNO3(aq) + LiOH(aq) -> LiNO3(aq) + H2O(l)}\): acid–base
  3. \(\ce{Pb(NO3)2(aq) + K2CrO4(aq) -> PbCrO4(s) + 2 KNO3(aq)}\): precipitation
2. Write the complete ionic and net ionic equations for \(\ce{Ba(NO3)2(aq) + K2SO4(aq) -> BaSO4(s) + 2 KNO3(aq)}\):
  1. Complete ionic:
  2. Spectator ions: \(\ce{K+}\) and \(\ce{NO3-}\)
  3. Net ionic: \(\ce{Ba^2+ + SO4^2- -> BaSO4(s)}\)
3. Write net ionic equations:
  1. \(\ce{Na2S(aq) + Zn(NO3)2(aq)}\): \(\ce{Zn^2+ + S^2- -> ZnS(s)}\)
  2. \(\ce{HBr(aq) + NaOH(aq)}\): \(\ce{H+ + OH^- -> H2O(l)}\)
  3. \(\ce{HC2H3O2(aq) + KOH(aq)}\):
  4. \(\ce{NH3(aq) + HCl(aq)}\): \(\ce{NH3 + H+ -> NH4+}\)
4. Explain why (b) and (c) above have different net ionic equations, even though both are “an acid reacting with a strong base.”
5. Predict the products, write the balanced formula equation, and state whether a precipitate forms:
  1. \(\ce{AgNO3(aq) + K2CrO4(aq)}\)
  2. \(\ce{NaCl(aq) + Mg(NO3)2(aq)}\)
6. Classify and explain:
  1. Is \(\ce{NH3}\) an Arrhenius base? A Bronsted–Lowry base? Explain the difference.
  2. Name the six strong acids.
7. Three different reactant pairs all give the net ionic equation \(\ce{Ag+(aq) + Cl^-(aq) -> AgCl(s)}\). Write formula equations for two of them.
