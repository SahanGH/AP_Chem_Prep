Unit 2 • Compound Structure and Properties

Worksheet 2 • Lewis, Formal Charge, Resonance

CED 2.5, 2.6 • electron count first, always

Directions & data
Start every structure with the total electron count written down — uncounted structures are uncheckable, and the count catches most errors before they happen.
1. For each species: electron count, then the Lewis diagram.
  1. \(\ce{OF2}\)   count: 20
    F–O–F; 2 lone pairs on O, 3 on each F. Bent shape comes later — the diagram just needs correct pairs.
  2. \(\ce{C2H4}\)   count: 12
    H\(_2\)C=CH\(_2\); double bond, no lone pairs.
  3. \(\ce{NO2-}\)   count: 18
    Two resonance forms: N central, one N=O and one N–O, lone pair on N; brackets, \(-\).
  4. \(\ce{XeF2}\)   count: 22
    F–Xe–F with THREE lone pairs on Xe — expanded octet (period 5).
2. Compute formal charges for the sulfate skeleton drawn with four single bonds (32 e\(^-\)):
  1. FC on S: \(+2\)   FC on each O: \(-1\)
  2. Verify the sum against the ion's charge. \(+2 + 4(-1) = -2\) ✓
3. Cyanide, \(\ce{CN-}\) (10 e\(^-\)), could be drawn C\(\equiv\)N with the lone pair on C or on N shifted variants. The accepted structure puts \(FC(\ce{C}) = -1\), \(FC(\ce{N}) = 0\). A student objects: “negative charge should sit on the MORE electronegative atom — this structure is wrong.” Respond.
4. Ozone, \(\ce{O3}\) (18 e\(^-\)).
  1. Draw both resonance forms.
    Central O with lone pair; O=O and O–O swapping; each form 18 e\(^-\).
  2. Both O–O bonds measure 128 pm. A true O=O is 121 pm; O–O single is 148 pm. Explain how this is evidence for the resonance hybrid.
  3. Bond order: \(3/2\)
5. The diagram police: each structure below contains one error. Identify it.
  1. \(\ce{BF3}\) drawn with a B=F double bond “to complete boron's octet.”
  2. \(\ce{SF4}\) drawn with only 8 electrons on S when the count demands more.
