Chapter 13 • Chemical Equilibrium

Chapter Test

Zumdahl §13.1–13.7 • 50 minutes • $R = §I0.08206$

Section I • Multiple Choice 20 questions • 30 minutes • 1 point each

1. At chemical equilibrium,
  1. both reactions have stopped
  2. the forward and reverse rates are equal
  3. reactant and product concentrations are equal
  4. only the forward reaction continues
2. Which statement about a system at equilibrium is correct?
  1. Concentrations of all species are identical
  2. Concentrations remain constant over time
  3. No molecules are reacting
  4. The reaction has gone to completion
3. Starting with pure products instead of pure reactants at the same temperature leads to
  1. the same equilibrium state
  2. a different value of \(K\)
  3. no reaction at all
  4. a permanently different set of concentrations
4. The equilibrium expression for \(\ce{2 SO2(g) + O2(g) <=> 2 SO3(g)}\) is
  1. \([\ce{SO3}]^2/([\ce{SO2}]^2[\ce{O2}])\)
  2. \([\ce{SO2}]^2[\ce{O2}]/[\ce{SO3}]^2\)
  3. \([\ce{SO3}]/([\ce{SO2}][\ce{O2}])\)
  4. \(2[\ce{SO3}]/(2[\ce{SO2}] + [\ce{O2}])\)
5. A reaction has \(K = 8.0\). The equilibrium constant for the reverse reaction is
  1. 8.0
  2. \(-8.0\)
  3. 0.125
  4. 64
6. If all coefficients in a balanced equation are doubled, the new equilibrium constant is
  1. \(2K\)
  2. \(K^2\)
  3. \(K/2\)
  4. unchanged
7. Which species is omitted from an equilibrium expression?
  1. a gas
  2. an aqueous ion
  3. a pure solid
  4. a dissolved molecule
8. For \(\ce{CaCO3(s) <=> CaO(s) + CO2(g)}\), the expression for \(K_p\) is
  1. \(P_{\ce{CaO}}P_{\ce{CO2}}/P_{\ce{CaCO3}}\)
  2. \(P_{\ce{CO2}}\)
  3. \(1/P_{\ce{CO2}}\)
  4. \(P_{\ce{CaO}}P_{\ce{CO2}}\)
9. For which reaction does \(K_p = K_c\)?
  1. \(\ce{N2(g) + 3 H2(g) <=> 2 NH3(g)}\)
  2. \(\ce{H2(g) + I2(g) <=> 2 HI(g)}\)
  3. \(\ce{2 NO2(g) <=> N2O4(g)}\)
  4. \(\ce{PCl5(g) <=> PCl3(g) + Cl2(g)}\)
10. For \(\ce{N2O4(g) <=> 2 NO2(g)}\), \(\Delta n\) equals
  1. \(+1\)
  2. \(-1\)
  3. 0
  4. \(+2\)
11. In the relation \(K_p = K_c(RT)^{\Delta n}\), \(\Delta n\) counts
  1. all species in the equation
  2. gaseous species only
  3. solids and liquids only
  4. aqueous species only
12. A reaction has \(K = 4\times10^{-8}\). At equilibrium the mixture consists mostly of
  1. products
  2. reactants
  3. equal amounts of both
  4. neither — no reaction occurs
13. A reaction has \(K = 10^{18}\) but produces no detectable product in a day. The best explanation is that
  1. the value of \(K\) must be wrong
  2. the activation energy is large, so the reaction is very slow
  3. the reaction is at equilibrium already
  4. \(K\) decreases over time
14. If \(Q < K\) for a reaction mixture, the system will
  1. shift toward products
  2. shift toward reactants
  3. remain unchanged
  4. change the value of \(K\)
15. The reaction quotient \(Q\) differs from \(K\) in that \(Q\)
  1. uses a different algebraic form
  2. uses current concentrations, which need not be equilibrium values
  3. applies only to gases
  4. has units
16. For \(\ce{2 HI <=> H2 + I2}\) starting with 0.500 M \(\ce{HI}\), the equilibrium concentration of \(\ce{HI}\) is
  1. \(0.500 - x\)
  2. \(0.500 - 2x\)
  3. \(0.500 + 2x\)
  4. \(2x\)
17. The small-\(x\) approximation in an equilibrium calculation is justified when
  1. \(K\) is very large
  2. \(K\) is very small
  3. the reaction is exothermic
  4. a catalyst is present
18. After using the small-\(x\) approximation, a student finds \(x\) is 12% of the initial concentration. The correct response is to
  1. accept the answer
  2. discard the approximation and solve the quadratic
  3. double the value of \(x\)
  4. recalculate \(K\)
19. A quadratic yields \(x = 0.30\) and \(x = 1.80\), with an initial reactant concentration of 1.00 M. The correct root is
  1. 0.30, because 1.80 gives a negative concentration
  2. 1.80, because it is larger
  3. their average
  4. either one
20. Which change alters the numerical value of the equilibrium constant?
  1. adding a reactant
  2. decreasing the volume
  3. changing the temperature
  4. adding a catalyst

Section II • Free Response 2 questions • 20 minutes

Free-response 1 • short • 4 points

For \(\ce{N2O4(g) <=> 2 NO2(g)}\), \(K_c = 4.6\times10^{-3}\) at 25 °C. A sealed flask initially contains 2.00 M \(\ce{N2O4}\) and no \(\ce{NO2}\).

  1. Construct the ICE table.
  2. Solve for the equilibrium concentrations, using the small-\(x\) approximation.
  3. Justify the approximation with an explicit check.

Free-response 2 • short • 4 points

Consider \(\ce{CO(g) + 2 H2(g) <=> CH3OH(g)}\), \(\Delta H = -91\,\mathrm{kJ}\), at equilibrium in a sealed vessel.

  1. Predict the direction of shift when the volume of the vessel is decreased, and explain.
  2. Predict the effect of raising the temperature on both the direction of shift and the value of \(K\).
  3. Argon is added at constant volume. State the effect and explain.
