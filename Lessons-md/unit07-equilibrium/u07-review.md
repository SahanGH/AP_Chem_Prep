## The five tools

| **$Q$ versus $K$** | $QK$
  shift left. Works for *any* mixture, equilibrium or not — the one
  tool that answers “which way?” |
|---|---|
| **Writing $K$** | products over reactants, each raised to its
  coefficient. Omit pure solids and pure liquids. H₂O(l) out,
  H₂O(g) in |
| **ICE** | change row follows the coefficients; approximate only if
  justified, and *report the percentage*. Perfect squares beat the
  quadratic formula |
| **Manipulating $K$** | reverse $\to 1/K$; $\times n$ coefficients
  $\to K^n$; add reactions $\to K_1K_2$. Constants multiply where
  enthalpies add |
| **Le Ch\^atelier** | the system opposes the change. Only
  **temperature** alters the value of $K$ |

## The disturbance table

| **Disturbance** | **Shift** | **$K$?** |
|---|---|---|
| add reactant / remove product | right | unchanged |
| add product / remove reactant | left | unchanged |
| compress (smaller volume) | toward fewer moles of gas | unchanged |
| add inert gas at constant $V$ | none | unchanged |
| add catalyst | none | unchanged |
| raise $T$, forward endothermic | right | **increases** |
| raise $T$, forward exothermic | left | **decreases** |

## Solubility, in four lines

- MX: $K_{sp} = s^2$. MX₂ or M₂X:
   $K_{sp} = 4s^3$.
- $K_{sp}$ is a *constant*; solubility is a *position*
   that changes with what else is dissolved.
- Common ion $\Rightarrow$ $Q$ exceeds $K_{sp}$ $\Rightarrow$ less
   dissolves. $K_{sp}$ itself never moves.
- Compare $K_{sp}$ values directly **only** when the salts
   release the same number of ions.

## The traps, one line each

- Saying equilibrium means equal concentrations (it means equal
   rates).
- Including a pure solid or liquid in $K$.
- Forgetting an exponent — $(0.30)^3$ is $0.027$, not $0.90$.
- Using the small-$x$ approximation without checking, or checking and
   ignoring the result.
- Claiming a catalyst or an inert gas shifts an equilibrium.
- Saying a concentration change alters $K$.
- Comparing $K_{sp}$ for salts with different ion counts.

> 📌 **How to study for this exam**
>
> This is a 44-point exam, one of the two largest in the course, so budget
> accordingly. Redo WS 5's FRQ cold — the long free-response is its twin in
> shape, and it deliberately runs the full chain: expression $\to$ ICE $\to$
> solve $\to$ verify $\to$ $Q$ versus $K$ $\to$ effect of a disturbance.
> 
> Two habits are worth more than any extra content. First, whenever you write
> “shifts right,” add *because $Q  justification is usually the point that the qualitative one is not. Second,
> whenever you approximate, write the percentage down. Both are cheap, and
> both are routinely omitted.
