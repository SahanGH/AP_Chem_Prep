## The seven tools

| **IMF identification** | LDF in everything; dipole–dipole if polar;
  H-bonding only if H is on N, O, or F; ion–dipole for salts in polar
  solvent. *Compare size first when molecules differ greatly* |
|---|---|
| **IMF consequences** | stronger IMF $\to$ higher bp, viscosity, surface
  tension; *lower* vapor pressure |
| **Solid classification** | ionic / metallic / covalent network /
  molecular — predict mp, hardness, conductivity from the particle type |
| **Gas laws** | $PV = nRT$ ($R = 0.08206$), kelvin always;
  $P_A = \chi_A P_{\text{tot}}$ |
| **KMT** | $KE_{\text{avg}} \propto T$ only; $u \propto 1/\sqrt{M}$;
  hotter $=$ broader, flatter, right-shifted, same area |
| **Solutions** | $M =$ mol solute / L *solution*;
  $M_1V_1 = M_2V_2$; ionic solutes drawn fully dissociated in ratio |
| **Beer–Lambert** | $A = \epsilon bc$; calibration slope $= \epsilon b$;
  unknown $c = A \div \text{slope}$ |

## Two deviation stories, kept straight

- **$PV/nRT  1$** — *particle volume* dominates (high
   $P$). The gas cannot compress as far as the ideal law predicts.
- Most ideal: **high $T$, low $P$**. Most deviant: strong IMFs
   (H₂O, NH₃) at low $T$, high $P$.

## Separation: name the property, not just the technique

filtration $\to$ particle size • distillation $\to$ boiling point
• chromatography $\to$ relative attraction to stationary vs
mobile phase

## The traps, one line each

- Ranking by force *type* alone — BI₃ outboils NH₃
   because dispersion scales with electron count.
- Celsius in a gas law. Convert first, every time.
- “Melting breaks the covalent bonds” — melting a molecular solid
   breaks only IMFs.
- “Real gases deviate because they're real” — name volume
   *or* attractions, and say which direction.
- Drawing ionic solutions as intact units instead of separated ions
   in the correct ratio.
- Multiplying by the Beer–Lambert slope instead of dividing.
- Forgetting $\nu = c/\lambda$ — the equations sheet gives only
   $E = h\nu$.
