> 📌 **Directions & data**
>
> State which plot is linear before computing anything. Remember
> that $\ln[\text{A}]$ is linear in time for first order — concentrations
> themselves are not, so never average them.

**1.** Complete the table from memory:

| **Order** | **Integrated form** | **Linear plot** | **Half-life** |
|---|---|---|---|
| 0 | $[\text{A}]_t = -kt + [\text{A}]_0$ | $[\text{A}]$ vs $t$ | $[\text{A}]_0/2k$ |
| 1 | $\ln[\text{A}]_t = -kt + \ln[\text{A}]_0$ | $\ln[\text{A}]$ vs $t$ | $0.693/k$ |
| 2 | $1/[\text{A}]_t = kt + 1/[\text{A}]_0$ | $1/[\text{A}]$ vs $t$ | $1/(k[\text{A}]_0)$ |

   second
