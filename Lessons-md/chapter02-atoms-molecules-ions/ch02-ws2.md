> 📌 **Directions & data**
>
> Write the compound TYPE beside each answer (I ionic-fixed,
> II ionic-variable, III covalent, A acid). Naming errors are almost always
> type-identification errors.

**1.** Name each ionic compound (Type I — fixed-charge metal):

1. KBr: potassium bromide
2. MgS: magnesium sulfide
3. Al₂O₃: aluminum oxide
4. Ca₃N₂: calcium nitride
5. ZnCl₂: zinc chloride (no numeral needed)

**2.** Name each (Type II — variable-charge metal). Deduce the charge
from the anions first.

1. FeCl₂: iron(II) chloride
2. Cu₂O: copper(I) oxide
3. SnO₂: tin(IV) oxide
4. PbS: lead(II) sulfide
5. Cr₂S₃: chromium(III) sulfide

**3.** Name each compound containing a polyatomic ion:

1. Na₂SO₄: sodium sulfate
2. Mg(OH)₂: magnesium hydroxide
3. Fe(NO₃)₃: iron(III) nitrate
4. (NH₄)₂CO₃: ammonium carbonate
5. KH₂PO₄: potassium dihydrogen phosphate
6. Ca(ClO)₂: calcium hypochlorite

**4.** Name each binary covalent compound (Type III):

1. SO₃: sulfur trioxide
2. N₂O₄: dinitrogen tetroxide
3. PCl₅: phosphorus pentachloride
4. CCl₄: carbon tetrachloride

**5.** Name each acid:

1. HBr(aq): hydrobromic acid
2. HNO₃(aq): nitric acid
3. H₂SO₃(aq): sulfurous acid
4. H₃PO₄(aq): phosphoric acid

**6.** Write the formula for each name:

1. barium hydroxide: Ba(OH)₂
2. manganese(II) nitrate: Mn(NO₃)₂
3. diphosphorus pentoxide: P₂O₅
4. ammonium phosphate: (NH₄)₃PO₄
5. hydrofluoric acid: HF(aq)
6. sodium hypochlorite: NaOCl
7. copper(II) sulfate: CuSO₄
8. potassium bromate: KBrO₃

**7.** Error hunt — each name below is wrong. Give the correct one and
say which rule was broken.

FeO called “iron oxide”
        

Mg₃N₂ called “trimagnesium dinitride”
        

Cu(NO₃)₂ called “copper(II) nitride”
