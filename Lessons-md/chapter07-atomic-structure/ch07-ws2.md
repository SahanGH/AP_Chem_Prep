> 📌 **Directions & data**
>
> Write configurations from memory using the periodic table's block
> structure, then check. For ions, adjust the electron count before you write
> anything.

**1.** Write full electron configurations:

1. N: $1s^2 2s^2 2p^3$
2. Al: $1s^2 2s^2 2p^6 3s^2 3p^1$
3. Ar: $1s^2 2s^2 2p^6 3s^2 3p^6$

**2.** Write noble-gas shorthand configurations:

1. Se: $[\text{Ar}]4s^2 3d^{10} 4p^4$
2. Sr: $[\text{Kr}]5s^2$
3. Mn: $[\text{Ar}]4s^2 3d^5$
4. I: $[\text{Kr}]5s^2 4d^{10} 5p^5$

**3.** Ions — adjust the electron count first:

1. Ca²⁺: $[\text{Ar}]$
2. P³⁻: $[\text{Ar}]$
3. Fe²⁺: $[\text{Ar}]3d^6$
4. Fe³⁺: $[\text{Ar}]3d^5$
5. Zn²⁺: $[\text{Ar}]3d^{10}$

**4.** Transition-metal cations lose 4$s$ electrons before 3$d$, even
though 4$s$ filled first. State the rule and apply it to explain why
Fe²⁺ is $[\text{Ar}]3d^6$ rather than $[\text{Ar}]4s^2 3d^4$.

**5.** Unpaired electrons. Give the number in the ground state:

1. C: 2
2. O: 2
3. Fe³⁺: 5
4. Zn: 0

**6.** Classify each as ground state, excited state, or impossible —
and identify the species where one exists:

1. $1s^2 2s^2 2p^6 3s^1$:
   ground — Na
2. $1s^2 2s^2 2p^6 3s^2 3p^5 4s^1$ (18 e$^-$):
   excited Ar
3. $1s^2 2s^2 2p^6 3s^3$:
   impossible ($s$ max 2)
4. $1s^2 2s^1 2p^1$ (4 e$^-$):
   excited Be

**7.** The two exceptions:

1. Predicted vs actual configuration of Cr:
   $[\text{Ar}]4s^2 3d^4$ vs $[\text{Ar}]4s^1 3d^5$
2. Predicted vs actual configuration of Cu:
   $[\text{Ar}]4s^2 3d^9$ vs $[\text{Ar}]4s^1 3d^{10}$
3. Give the reason both anomalies occur.
   

**8.** Name three species isoelectronic with Ne and state their
shared configuration.
